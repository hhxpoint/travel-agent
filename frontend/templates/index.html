ℹ️ 关于旅智

旅游攻略智能体项目介绍

🗺️ 旅智 - 旅游攻略智能助手

本项目是一个基于大语言模型和LangChain框架开发的旅游攻略智能体，能够为用户提供旅游攻略的推荐、咨询和管理服务。

🔧 技术栈

  • 大模型框架：LangChain + LangChain Agent
  • 后端：Python + Flask
  • 前端：HTML5 + CSS3 + JavaScript
  • 向量数据库：ChromaDB
  • 大模型：支持OpenAI兼容接口（智谱GLM、通义千问等）
  • 工具协议：MCP (Model Context Protocol)

✨ 核心功能

  • 🤖 智能对话 - 自然语言交互，智能推荐攻略
  • 🔍 多维搜索 - 按目的地、标签、预算、季节搜索
  • 📋 攻略浏览 - 浏览所有可用的旅游攻略
  • ➕ 攻略添加 - 用户可添加新的旅游攻略
  • 🔌 MCP服务 - 支持MCP协议，可被其他AI应用调用
  • 📊 RAG检索 - 基于向量数据库的语义检索

📚 使用指南

  1. 在「智能对话」中输入你的旅游问题
  2. 系统会自动搜索并推荐合适的攻略
  3. 你也可以在「攻略列表」中浏览所有攻略
  4. 如果有新的旅行经验，可以在「添加攻略」中分享
